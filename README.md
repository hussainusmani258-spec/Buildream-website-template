🏗️ Buildream - Construction & Architecture Website Template

Buildream is a modern, responsive, and high-performance HTML5/CSS3 website template designed specifically for construction companies, architectural firms, home builders, and engineering contractors.

🌐 Live Demo: Buildream Website

✨ Features

Responsive Design: Mobile-first layout fully optimized for mobile devices, tablets, and desktops.

Modern UI/UX: Clean, bold, industrial aesthetic tailored for construction & building agencies.

Hero Slider Section: Eye-catching hero section for highlighting core projects and services.

Project Gallery / Portfolio: Filterable showcase for displaying completed and ongoing projects.

Services Section: Dedicated cards highlighting services (e.g., Residential, Commercial, Renovation, Architecture).

Client Testimonials: Carousel slider for customer feedback and ratings.

Contact Form & Google Maps Integration: Built-in form interface and map integration for local client inquiries.

Cross-Browser Compatibility: Smooth performance across Chrome, Edge, Firefox, and Safari.

🛠️ Tech Stack & Technologies

HTML5: Semantic structural markup.

CSS3 / Bootstrap: Modern responsive styling framework and flexbox/grid architecture.

JavaScript (ES6+): Interactive carousels, mobile navigation toggle, and smooth scrolling animations.

Font Awesome / Google Fonts: Clean iconography and typography (Poppins/Open Sans).

🚀 Getting Started Locally

Follow these steps to run the project locally on your machine:

Clone the Repository:

git clone https://github.com/hussainusmani258-spec/Buildream-website-template.git


Navigate to the Directory:

cd Buildream-website-template


Run the Project:

Open index.html directly in your favorite browser.

Alternatively, use the Live Server extension in VS Code for live browser reloading.
